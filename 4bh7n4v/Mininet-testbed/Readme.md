# SDN Testbed Using Mininet and SDN Controllers

This project demonstrates the setup and testing of a Software-Defined Networking (SDN) testbed using Mininet. The testbed integrates hosts and switches with SDN controllers for centralized network management.

## Features

- Centralized network control using SDN controllers.
- Customizable network topologies with Mininet.
- Interoperability with multiple SDN controllers.
- Real-time monitoring of traffic flows and network performance.
